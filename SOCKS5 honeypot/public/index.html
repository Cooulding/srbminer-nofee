共享矿池与钱包

以下配置由所有 SOCKS5 入口复用

已知 dev 钱包名单

模式 1 据此选择重定向；两种模式均据此标记 dev 份额，并统一矿机名为 devfee。内置名单自动保留，可补充其他 dev 钱包。匹配忽略 .矿机名 和 + 协议后缀；白名单钱包地址保留。

NOCK 双挖白名单

PRL 端口 3360 / 3361 / 3362

PRL 矿池端口为 3360 / 3361 / 3362 且登录带 +NOCK 双挖后缀时生效：白名单内保留原 NOCK 地址，否则替换为第一项；发往矿池的钱包统一为 PRL钱包+NOCK钱包.矿机名。留空表示不替换 NOCK 地址。

本地 TLS 证书

自定义 CA 会按原目标域名签发证书；自定义服务端证书会直接使用，需要覆盖 miner 请求的域名。可从首页下载当前使用的信任证书。

保存会断开当前矿池连接。miner 重连后使用新的矿池、钱包及证书配置。
